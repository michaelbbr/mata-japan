明治神宮不能跑步：新宿走到原宿這條路，跑者最容易踩的雷

森林再大、參道再寬，那裡是神社，不是操場

住在東京的跑者，大概都動過這個念頭：從新宿一路跑向原宿，途中切進明治神宮的森林，樹蔭又涼，參道又寬，簡直是市中心最奢侈的跑道。

先打住。明治神宮官網的參拜禮儀頁寫得很清楚，境內請勿跑步，也請勿從事運動。理由不難懂，那片森林再怎麼像公園，本質上都是神社的境內，是別人來參拜、來安靜走路的地方，不是練間歇的場地。

我們站上就有人差點跑進去，被警衛注意到，當場收起腳步裝作散步。那個畫面我光想就覺得好笑，但笑完要講正經的：被提醒不是因為你跑得慢，是因為跑步這件事本身就不在那個空間的規則裡！

那住在這一帶的人，週末想跑該怎麼安排？我的做法是把明治神宮留給散步，把跑步放在神宮外苑那一側。從新宿出發，先用走的穿過神宮境內，沉澱一下，出到原宿或外苑再起跑。這樣安排有個意外的好處，熱身的距離剛剛好，心也靜下來了，起跑之後反而更穩。

還有一件事要提醒：神宮的開門與閉門時間跟著日出日落走，每個月都不一樣。冬天閉門早，下午去散步要先查官網的月份時間表，不要跑到門口才發現已經關了，站在鐵門前面吹風，那又是另一種糗。

腸鍋的結論：會分清楚哪裡能跑、哪裡只能走，才是住在這裡的跑者。東京的綠地很多，不差神宮這一塊，把敬意留給神社，把汗留給外苑，這樣分配剛剛好。
