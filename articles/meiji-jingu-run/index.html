明治神宮不能跑步，參道再寬也是神社

樹蔭再涼、參道再寬，官網寫了，境內不能跑步

住在東京的跑者，大概都動過這個念頭：從新宿一路跑向原宿，途中切進明治神宮的森林，樹蔭又涼，參道又寬，根本是市中心現成的跑道。

我也動過這個念頭。明治神宮官網的參拜禮儀頁寫得很清楚，境內請勿跑步，也請勿從事運動。那片森林再怎麼像公園，底子是神社的境內，人家是來參拜、來安靜走路的，你在旁邊衝圈數，不用警衛開口，自己都覺得吵。

我們站上就有人差點跑進去，被警衛注意到，當場收起腳步裝作散步。裝得還挺像，警衛也就沒有再多看他一眼。被提醒的原因跟速度無關，慢跑也一樣，跑步這件事本身就不在那個空間的規則裡。

🌲 我現在的跑法是把兩邊分開用。從新宿出發，用走的穿過神宮境內，出到原宿那一側再起跑，跑步放在神宮外苑那邊。這樣排還有個實際的好處，走路那一段剛好是熱身的距離，起跑之後身體已經熱開了，步伐反而穩。

時間也要看一下。神宮的開門、閉門跟著日出日落走，每個月都不一樣，冬天關得早。下午才出門散步的人，出發前查一下官網的月份時間表，免得走到門口，只剩鐵門和風。

原始資料

  • 明治神宮官網 Etiquette 頁：境內請勿跑步或從事運動，並請保持神聖場所的莊重
  • 明治神宮官網參拜時間說明：開閉門依日出日落按月調整，出發前請查官網月份時間表（同站）
